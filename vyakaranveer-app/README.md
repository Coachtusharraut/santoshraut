# व्याकरणवीर — मराठी व्याकरणाची शब्दयात्रा

A mobile-friendly, story-based Marathi grammar learning game for students in Classes 8–10.

## Run locally
Open `index.html` in a modern browser. Keep the `assets` folder beside it so the Santosh Raut branding portrait loads correctly.

## Deploy free
This is a static website: it needs no server, database, or paid runtime. You can host it on GitHub Pages, Cloudflare Pages, or Firebase Hosting's free tier. Upload the complete folder (not just `index.html`) so `assets/santosh-raut.jpg` is included. Once published, the host provides a public HTTPS URL that can be shared with students, parents, and teachers.

## What's included
- 17 interactive missions with short explanations, relatable Maharashtra-based scenarios, quizzes, hints, feedback, XP and badges.
- Grade selector for Classes 8, 9 and 10.
- Student name, progress and scores saved locally in the browser on that device.
- Share buttons for the game and a quiz result.
- Branding panel and portrait for Santosh Raut.

## Important notes
- This is an independent learning aid, not an official Maharashtra State Board product.
- Topics and depth can vary by school and textbook; teachers should cross-check the content against the student's current prescribed textbook.
- Progress is stored only in the current browser/device. There are no accounts, cloud sync or shared leaderboard at this stage.
